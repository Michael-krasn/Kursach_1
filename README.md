
# Анализ транзакций (курсовая работа)

## Описание проекта
Приложение предназначено для анализа банковских транзакций,
хранящихся в Excel-файле. Проект формирует аналитические отчёты
и сохраняет их в формате JSON.

## Реализованные возможности
- Загрузка данных из Excel (pandas)
- Отчёты:
  - Траты по категории
  - Траты по дням недели
  - Траты в рабочий и выходной день
- Декоратор для автоматического сохранения отчётов в JSON
- Логирование всех ключевых операций
- Pytest-тесты бизнес-логики
- Разделение бизнес-логики и ввода данных

## Стек технологий
- Python 3.10+
- pandas
- pytest
- logging
- json
- datetime

## Структура проекта
```
src/

 ├── decorators.py
 └── main.py
tests/
 ├── conftest.py
 └── test_reports.py
data/
 └── operations.xlsx
```

## Установка зависимостей
```bash
pip install -r requirements.txt
```

## Запуск приложения
```bash
python src/main.py
```

## Запуск тестов
```bash
pytest
```

## Примечание
Бизнес-логика не зависит от источника данных,
что позволяет легко заменить Excel на API или БД.
